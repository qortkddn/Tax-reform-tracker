# 2026 세제개편 시뮬레이터

2026년 세제개편안(정부안)을 세목별로 추적하고, 개인별 세액 변화를 **누진세율 기준 통합 계산**으로 보여주는 웹 계산기입니다.
회계법인(세무자문) 입사 포트폴리오로, Claude와 함께 기획부터 구현까지 진행했습니다.

> ⚠️ 정부안 기준이며 국회 본회의(2026년 12월 예정) 통과 전입니다. 계산 결과는 참고용 추정치이며 세무 자문이 아닙니다.

## 계산 로직

- **법인세**: 과세표준 → 누진세율(10~25%) → R&D·투자 세액공제 → 최저한세(중소 7%, 일반 10~17%) 순서로 통합 계산. 중소기업 R&D 공제는 최저한세 제외. 자기주식을 판 주주는 이자·배당소득 2,000만원 초과 시 종합과세(비교과세·배당세액공제 반영)
- **내 집 한 채**: 집 정보를 한 번 입력하면 취득세 → 매년 재산세·종부세 → 양도세(취득세를 필요경비로 반영)를 이어서 계산해 현행과 정부안의 총 세금을 비교

- **종합소득세**: 과세표준 재계산(부양가족 공제·업무용 승용차 비용) → 누진세율 → 세액공제(월세·육아휴직, 산출세액 한도) → 지방소득세 10%. 근로장려금은 세액이 아닌 지급액이라 별도 표시
- **부가가치세**: 의제매입세액공제 차감 후, 남은 납부세액 한도 안에서 신용카드 공제
- **양도소득세**: 양도차익 → 12억 초과분 안분 → 장특공제(중과 시 배제) → 기본공제 → 세율(기본·중과·단기 중 큰 것, 미등기 70%) → 감면 → 농어촌특별세 20%

항목별 효과의 단순 합은 누진세율 때문에 실제와 달라지므로, 세목별 **통합 계산**을 따로 보여줍니다.

## 가정과 한계

- 장특공제 정부안의 연수별 최대 공제율: 보유·거주 각 10년까지로 가정
- 중과 완화 기간에도 장특공제 배제로 가정, 2026년 양도분 소급·중과 배제 주택·등록임대 특례 미반영
- 고령자 감면 한도와 농특세 적용 여부 미확인
- 부양가족 중복공제, 의제매입 공제한도, 간이과세자 구조 미반영

## 테스트

**법령 대조 테스트 (데이터마이닝)**: `scripts/fetch_laws.py`가 법제처 국가법령정보 Open API로 계산에 쓰는 조문(소득세법 §17·§55, 법인세법 §55, 조특법 §6·§127·§132)을 수집해 `data/laws.json`에 저장하고, `tests/law.test.js`가 조문 원문에서 세율("6퍼센트", "100분의 11")과 금액 구간("1억5천만원")을 뽑아 시뮬레이터 계산값과 대조합니다. 조문이 개정되면 테스트가 실패해 바로 알 수 있어요. `.github/workflows/laws.yml`이 매주 자동 수집합니다 (저장소 Secret `LAW_OC` 필요).

커밋할 때 `index.html` 하단의 **최종 수정일**이 자동으로 오늘 날짜로 바뀝니다 (`scripts/pre-commit`, 설치: `cp scripts/pre-commit .git/hooks/pre-commit`).

배포 전에 카드 넘기기(이전/다음, 항목 칩, 스와이프)에서 상단 칩·번호가 실제 카드와 맞는지 휴대폰·PC 화면으로 자동 검사합니다.

```
NODE_PATH=$(npm root -g) node tests/carousel.test.js   # 카드 넘기기·화면 검사
NODE_PATH=$(npm root -g) node tests/calc.test.js       # 손으로 검산한 22개 예시의 세액 검사
```

`calc.test.js`는 종소세·근로장려금·취득세·재산세·종부세·양도세·코인 세금의 예시 계산을 손계산 결과와 대조해, 수정 중에 계산이 틀어지면 바로 실패합니다.
