# 프로젝트 일지

세법 개정을 AI로 추적·계산하는 트래커. 세법 지식 자체보다 **세법을 AI와 어떻게 엮어 일하는가**(역할 분담·검증·도구 연동)를 기록합니다.

## AI 활용 구조

| 단계 | AI가 한 일 | 내가 한 일 |
| --- | --- | --- |
| 조사 | 웹 검색으로 정부안·보도자료 수집, 출처 표시 | 의미 있는 항목 선별, 실질 영향 없는 항목 제외 기준 제시 |
| 설계 | 화면 구조와 계산 흐름 제안 | 핵심 가치 정의, 방향 수정(국회 심의 현황 → 본회의 통과·변경점) |
| 계산 | 세법 수식을 코드로 구현 | 세법 논리 오류 지적(누진세율, 등기/미등기, 재산 평가 기준) |
| 검증 | 헤드리스 브라우저 자동 테스트, 수계산 대조 | 세법적 타당성 검토, 출처 없는 부분 교재로 재검증 |
| 배포·기록 | GitHub 커밋, Pages 배포, 노션 일지 업데이트 | GitHub 앱·노션 연동 설정 |

## AI 활용 원칙

1. 숫자는 AI가 말로 추정하지 않고 코드로 계산한다
2. 미확정·미확인 정보는 화면에 '가정'으로 표시하고 출처를 붙인다
3. AI 결과는 반드시 실행해서 검증하고, 세법 지식으로 한 번 더 본다
4. AI가 출처 없이 쓴 내용은 스스로 밝히게 하고, 검증 책임은 내가 진다
5. AI에게 선별 기준을 준다 — 실질 영향이 있는 것만

- **배운 점**: AI는 빠르게 만들지만, 정확도는 사람이 던지는 질문의 수준만큼 올라간다
